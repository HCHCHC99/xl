## 1. 参考工程 mode 40 架构

```
编码器计数 → 5ms 速度测量/滤波 → 5ms 速度 PI → iq_ref(mA)
                                                    ↓
20kHz 电流环：id/iq PI → vd/vq → InvPark → SVPWM → PWM
```

特点：

- 速度环 5ms 一次；电流环每个 20kHz ISR 一次
- 速度环输出直接作为 `iq_ref`，`id_ref = 0`
- 速度给定经加速度斜坡（1950 rpm/s）
- 速度反馈：编码器每拍增量累加 5ms，再 EMA α=0.25
- 启动前要求 mode 24 校准完成（编码器零点 + 电流零偏）
- 模式自持 18ch VOFA 布局
- 过流由 `Foc_Core_OverCurrent` 处理

|---|---|

## 3. 建议的移植设计

### 3.1 新增 `ws/foc_speed_loop.c/.h`

接口：

```c
void Foc_Speed_Init(void);
void Foc_Speed_Start(void);                 /* 目标清 0，复位滤波/PI */
void Foc_Speed_Stop(void);
void Foc_Speed_SetTargetRPM(float rpm);
void Foc_Speed_Task20k(void);               /* 每拍调用，内部 5ms 抽稀 */
int  Foc_Speed_VofaFill(int32_t *cur);      /* 可选，18ch */
```

每 100 拍（5ms）流程：

1. 累加 `g_fc_enc_delta * g_enc_elec_dir`，**每拍先限幅 ±36**
2. `raw_rpm = sum * 60 * 200 / CPR`（5ms 窗口，CPR=4096）
3. `filt_rpm += 0.25 * (raw_rpm - filt_rpm)`
4. 目标限幅 ±7800 rpm；按 1950 rpm/s 斜坡（每 5ms 步进 9.75 rpm）
5. 速度 PI：
   ```
   err = ramp - filt
   P = 0.8 * err
   integral += err * 0.005
   integral 限幅 ±3400（rpm·s）
   I = 0.03 * integral，限幅 ±3400 mA
   out = P + I，限幅 ±3400 mA
   ```
6. `Foc_CurrentLoop_SetRefDirect(0, out / 1000.0f)`
7. 未进入电流环 active（预热/零偏校准中）时，只更新测量/斜坡，不积分、不输出 iq_ref

> 速度 PI 不直接用 `pid_ctrl`：参考 `integral_max=3400` 限的是**积分量 rpm·s**，
> 而 `pid_ctrl` 只有积分项输出限幅。单独写约 20 行 PI 才能复现参考的抗饱和行为。

### 3.2 `foc_mode.h/.c` 增加 `FOC_MODE_SPEED`

- 枚举新增 `FOC_MODE_SPEED`
- `Foc_Mode_Step()` 新增分支：

```c
case FOC_MODE_SPEED:
    Foc_Speed_Task20k();
    Foc_CurrentLoop_Step(&out->vd, &out->vq, &out->theta_e);
    out->enable = true;
    break;
```

- `Foc_Mode_SetMode(FOC_MODE_SPEED)` 同样调用 `Foc_CurrentLoop_Reset()`

### 3.3 `foc_current_loop.c/.h` 增加接口

1. `Foc_CurrentLoop_SetRefDirect(float id_a, float iq_a)`
   - 直接写 `s_id_ref/s_iq_ref`，同时同步 `s_id_ref_ramped/s_iq_ref_ramped`
   - 绕过 1A/s 的 ref 斜坡，避免速度环输出被滞后
2. `uint8_t Foc_CurrentLoop_IsActive(void)`
   - 表示“预热 + 在线零偏校准完成、电流环真正开始”
   - 速度环在未 active 时只更新测量/斜坡，不积分、不输出

### 3.4 mode 9 参数切换

| 参数 | mode 9（速度） | mode 4/8（电流） |
|---|---|---|
| 电流 PI kp | 0.1 | 0.27 |
| 电流 PI ki | 300 | 630 |
| 电流环 vmax | 6.2 V | 3.5 V |
| 电流积分项限幅 | 6.0 V | 3.5 V |
| id/iq EMA | 1.0（关闭） | 0.3 |
| dq 前馈 | 默认 0 | mode4=0，mode8=1 |
| ref 来源 | 速度环直接给 | 主循环 Watch |

- 退出 mode 9 或进入 mode 4/8 时恢复 0.27/630、3.5/3.5、EMA 0.3
- 速度环 Watch：`g_spd_target_rpm`、`g_spd_kp`、`g_spd_ki`、`g_spd_accel_rpm_s`、`g_spd_iq_limit_ma`
- 速度模式电流环 Watch：建议单独 `g_spd_cur_kp/ki`，避免与 mode 4/8 的 `g_cl_kp/ki` 互相覆盖

### 3.5 `main.c` 增加 mode 9

- `g_mode_cmd = 9` 进入速度模式
- 入口检查复用 `CurrentLoop_EntryCheck()`
- 设置 3.4 的模式相关参数
- `Foc_Speed_Start()` 后 `Foc_Mode_SetMode(FOC_MODE_SPEED)`
- 新增 10ms `[SPD]` 打印：
  ```
  tgt= ramp= filt= meas= err= out= iq_r= iq= vd= vq= sat=
  ```
- 目标通过 `g_spd_target_rpm` Watch 写入

### 3.6 停止行为

参考工程约定：

1. `g_spd_target_rpm = 0`
2. 等减速到接近 0
3. `g_mode_cmd = 0`

建议先按手动流程；可选“目标 0 且速度 <50 rpm 持续 100ms 自动回 mode 0”。

## 4. 差异与风险

### 4.1 电流环参数不同（必须区分）

- mode 40：0.1/300、6.2V/6.0V、无 EMA
- 当前 mode 4/8：0.27/630、3.5V/3.5V、EMA 0.3
- mode 9 必须切到 mode 40 那套，否则无法复现参考的串级动态

### 4.2 速度环积分限幅按轻载调

参考 `integral_max=3400 rpm·s`，乘 ki=0.03 后 I 项最多约 102mA，适合云台轻载。推杆带丝杆负载时可能不够，会留下较大稳态转速差。

建议：

- 先按 3400 验证空载/轻载
- 带载时把积分限幅放大到 `iq_limit/ki`（3400/0.03 ≈ 113333 rpm·s）

### 4.3 速度反馈用新 5ms 估计器

当前 `g_enc_speed_rpm` 是主循环 10ms/α=0.2；参考是 ISR 内 5ms/α=0.25/每拍限幅 36。

建议速度模式用新 5ms 估计器，不改动 `hw_encoder` 的 10ms 速度（它仍用于在线零偏校准的 >50rpm 判断）。

### 4.4 在线零偏校准带来 210ms 预热

当前电流环进环后先做 50/50 在线零偏校准 + 210ms 预热；参考 mode 40 没有这段。

速度环在预热期不能积分，否则目标一给就把 iq_ref 积到限幅。用 `Foc_CurrentLoop_IsActive()` 门控。

### 4.5 VOFA

当前 17ch；参考 18ch。两种选择：

- 方案 A：先只做 10ms RTT `[SPD]` 打印
- 方案 B：mode 9 时切 18ch 速度布局（ch13 斜坡 / ch14 目标 / ch15 显示速度 / ch17 PI 反馈）

### 4.6 过流保护

参考用 `Foc_Core_OverCurrent`（9A 去抖）；当前用 `Foc_Protect`（20kHz 快/慢/确认）。速度模式无需额外保护，但要确保 3400mA 限幅低于保护阈值。

## 5. 验证计划

1. mode 3 或 mode 7 对齐，确认 `dir=-1`
2. mode 9，目标先设 0，确认预热后 iq≈0、vd/vq≈0
3. 目标 500 → 1000 rpm，观察：
   - `ramp` 以 1950 rpm/s 上升
   - `filt` 跟随 `ramp`，稳态误差小
   - `iq_r` 在 3400mA 限幅内
   - `vq` 不超过 6.2V；贴 6.2V = 撞电压墙
   - 0→1000 rpm 上升约 600ms、超调 <5%
4. 反向目标、目标 0 减速、mode 0 停机
5. 带载：观察 iq_r 是否到 3400mA 限幅、速度是否掉、积分是否足够
